# React + TypeScript practice

A small, reusable Vite workspace for timed coding exercises. The tooling is set
up; the exercise implementation is intentionally left to you.

## Run it

```bash
npm install
npm run dev
```

Then open the local URL printed in the terminal.

## Useful commands

```bash
npm run typecheck  # TypeScript only
npm run lint       # ESLint only
npm run build      # production build
npm run check      # run all three checks
```

For each exercise, replace the contents of `src/App.tsx` and `src/styles.css`.
Keep mock data and small supporting components under `src/` as needed. Avoid
installing component libraries during interview-style exercises unless the spec
explicitly permits them.
